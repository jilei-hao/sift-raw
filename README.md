# SiftRAW

A tiny macOS app to manually cull photos from a Sony A7III shoot. Open a folder of
`.ARW` + `.JPG` pairs, fly through them with keyboard shortcuts, then move/copy the
keepers and rejects into subfolders in one shot.

## Build

The Xcode project is generated by [xcodegen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen     # if you don't have it
xcodegen generate         # creates SiftRAW.xcodeproj
open SiftRAW.xcodeproj
```

Then hit Run in Xcode (or `xcodebuild -scheme SiftRAW build`).

## Keyboard shortcuts

| Key       | Action                                |
|-----------|---------------------------------------|
| `→`       | Next photo                            |
| `←`       | Previous photo                        |
| `Space`   | Toggle keep on current photo          |
| `⌘O`      | Choose source folder                  |
| `⌘T`      | Choose destination folder             |
| `⌘R`      | Reset all decisions (with confirm)    |
| `⌘Return` | Apply                                 |

## How it works

- Folder scan groups `.ARW`+`.JPG` by basename (case-insensitive) — one entry per shot.
- Preview always uses the `.JPG` when available (RAW only when there's no JPG companion)
  for instant scrolling. The original `.ARW` is never decoded for display.
- Every photo starts as **reject** by default. Hit `Space` to mark a photo as **keep**;
  hit `Space` again to flip it back.
- "Apply" creates `keep/` and `reject/` under the destination, then moves or copies
  every photo into the matching folder — both `.ARW` and `.JPG` together. Filename
  collisions get ` (n)` suffixes; no overwrites. Apply is disabled until at least one
  photo is marked keep.
- **Split RAW/JPG** (toolbar checkbox, default on) further sorts each file by type, so
  the layout becomes `keep/jpg/`, `keep/raw/`, `reject/jpg/`, `reject/raw/`. Turn it
  off to land everything flat in `keep/` and `reject/`.
- When source equals destination, Mode is forced to Move.

## Out of scope (v1)

- XMP / star ratings, direct deletion, video (`.MP4`), recursive multi-folder
  scans, decision persistence across restarts, SD-card auto-mount.
